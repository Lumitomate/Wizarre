# Domain Docs

Comment les skills doivent consommer la documentation de domaine de ce dépôt.

## Avant d'explorer, lire

- **`CONTEXT.md`** à la racine du dépôt
- **`docs/adr/`** — lire les ADR qui concernent le domaine concerné

Si ces fichiers n'existent pas, **continuer sans rien signaler**. Ne pas proposer de les créer spontanément.

## Structure

```
/
├── CONTEXT.md
├── docs/adr/
│   ├── 0001-...md
│   └── 0002-...md
└── src/
```
