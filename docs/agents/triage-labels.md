# Triage Labels

Les skills utilisent cinq rôles canoniques. Ce fichier mappe ces rôles aux étiquettes réelles utilisées dans ce dépôt.

| Rôle dans mattpocock/skills | Étiquette dans notre tracker | Signification |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Le mainteneur doit évaluer cette issue   |
| `needs-info`               | `needs-info`         | En attente d'informations du signalant   |
| `ready-for-agent`          | `ready-for-agent`    | Entièrement spécifié, prêt pour un agent  |
| `ready-for-human`          | `ready-for-human`    | Nécessite une implémentation humaine     |
| `wontfix`                  | `wontfix`            | Ne sera pas traité                        |
